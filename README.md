# Library Project

A simple console-based library management application.

## Features
- Add books and members
- Search for books by title
- Borrow and return books

## Concepts Used
OOP (encapsulation), List, HashMap, null checks, error handling



## Note
I did not write a `Main` class. I only tested the methods, so you can write your own `Main` and customize the project as you like.
